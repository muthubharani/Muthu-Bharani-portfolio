# Muthu Bharani P — Portfolio

A React + Vite portfolio site generated from the resume, styled with a
"dashboard" visual theme (mono accents, KPI tiles, terminal-style hero).

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

This creates a `dist/` folder containing the static site — this is what
you deploy.

## Editing content

All page copy lives in the small data arrays at the top of each file in
`src/components/` (Hero, About, Experience, Projects, Skills, Education,
Credentials, Contact). Edit those arrays to update text without touching
the layout/markup.
